# Телеграм-бот для продажу курсів

Бот продає курси з вашого ТГК за **Telegram Stars ⭐** і після оплати автоматично
видає одноразове запрошення в закритий канал/групу з матеріалами курсу.

## Можливості

- 📚 Каталог курсів з описом і ціною
- 💳 Оплата через Telegram Stars (без еквайрингу, комісій банку й договорів)
- 🔗 Автоматична видача одноразового посилання в закритий канал курсу
- 🎓 «Мої курси» — повторна видача посилання, якщо покупець його загубив
- 📢 Глибокі посилання для постів у ТГК: `t.me/ваш_бот?start=course_pro`
- 👑 Адмін-команди: статистика, повернення коштів, розсилка
- 🔔 Сповіщення адміну про кожну покупку

## Налаштування

1. **Створіть бота** в [@BotFather](https://t.me/BotFather) → `/newbot`, скопіюйте токен.
2. **Для кожного курсу створіть закритий канал** (або групу) з матеріалами.
   Додайте бота туди **адміністратором** з правом «Запрошувати користувачів».
3. **Дізнайтесь ID закритого каналу**: перешліть будь-який пост з нього боту
   [@userinfobot](https://t.me/userinfobot) або [@getidsbot](https://t.me/getidsbot).
   ID має вигляд `-100…`.
4. **Опишіть курси** у `courses.json`:
   ```json
   {
     "id": "pro",
     "title": "Курс «PRO»",
     "description": "Опис курсу (до 255 символів)",
     "price_stars": 1500,
     "chat_id": -1009876543210
   }
   ```
   `id` — латиницею, без пробілів (використовується в посиланнях).
5. **Створіть `.env`** з `.env.example` і заповніть `BOT_TOKEN`, `ADMIN_IDS`, `CHANNEL_URL`.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m bot
```

Для роботи 24/7 запустіть бота на VPS (наприклад, через `systemd` чи `screen`)
або на хостингу на кшталт Railway / Render / Fly.io.

## Команди адміністратора

| Команда | Що робить |
|---|---|
| `/stats` | Кількість користувачів, продажі та виручка по курсах |
| `/links` | Готові посилання на кожен курс для постів у ТГК |
| `/refund <ID платежу>` | Повертає зірки покупцю і прибирає його з каналу курсу (ID платежу приходить у сповіщенні про покупку) |
| `/broadcast <текст>` | Розсилка всім користувачам бота. Можна також відповісти `/broadcast` на будь-яке повідомлення (фото, відео тощо) |

## Про оплату

Telegram вимагає, щоб цифрові товари (а курси — це цифрові товари) продавались
саме за Telegram Stars. Отримані зірки можна вивести через
[Fragment](https://fragment.com) у TON або витратити на рекламу в Telegram.
Баланс видно в @BotFather → ваш бот → *Balance*.
